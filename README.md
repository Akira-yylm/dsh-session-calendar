# 会话日历 · Session calendar

[![Socket Badge](https://badge.socket.dev/npm/package/@akira-yylm/session-calendar)](https://socket.dev/npm/package/@akira-yylm/session-calendar)

> 非官方（unofficial）DeepSeek Harness 插件，与 DeepSeek 官方无关。English → [README.en.md](README.en.md)

在 DSH 左侧导航「免费会话」下方增加**一个「会话日历」按钮**：收起时是**透明底 + 中性细描边**（只有日历图标是品牌蓝 `#4D6BFE`）；**打开小窗后**才浮出一层很淡的蓝色（15%）+ 淡蓝描边，用颜色表示「这扇日历正开着」。点开后在左侧栏右边弹出小窗日历，选中某一天就能看到那一天的会话，并按各自所属的**工作区分组**排列（和左侧栏的会话属于同一个工作区结构）；**按「首次」还是「最近」归日，用小窗顶部的分段开关切**。

| 小窗顶部开关 | 会话按什么时间归到某一天 |
|---|---|
| **首次** | 这个会话**第一次**开始对话的时间（原逻辑） |
| **最近** | 这个会话**最近一次**你发消息的时间（今天又聊过的旧会话会出现在今天） |

点任意一条会话直接打开它。开关的选择会被记住，下次打开沿用上次的规则。

## 怎么用

1. 左侧导航「新会话」「免费会话」下方是**一个「会话日历」按钮**：收起时背景透明但保留中性细描边、只有蓝色日历图标；打开后铺一层 15% 品牌蓝 + 45% 淡蓝描边（宽度与上面那行一致，折叠成细栏时变成 36px 图标按钮）。
2. 点它：小窗出现在左侧栏右边、并在窗口内**纵向居中**（约 360px 宽、日期格 38px 高）。顶部第一行是月份标题，第二行是 `‹` `›` `今天` `×` 四个均分整行的按钮。高度固定（最多 720px），所以换日期时只有列表在滚动，月历格子不会跳动；会话很多时列表内部滚动，分组标题吸顶跟随。
3. **切换规则**：月份标题下面有一整行 **「首次｜最近」** 分段开关（每格约 160px 宽），点它就地重排（窗口不动），选择会记住；再点侧栏那个按钮才收起。
4. 有会话的日期，**边框就是当天（按当前规则）涉及的工作区颜色**（只有一个工作区是纯色；多个工作区是一条渐变色边框），下面还按工作区各有一个圆点；鼠标悬停能看到「工作区 · 条数」。点日期即可查看当天会话。
5. `‹` `›` 翻月（会自动落到该月最早有会话的那一天），「今天」回到当天。焦点在小窗里时也可以用**键盘方向键**：`←` `→` 前后一天、`↑` `↓` 前后一周（跨月自动翻月）。
6. 下方按工作区顺序分组，每组标题是该工作区的名字，组图标和每行的描边也用它自己的颜色；每条显示会话标题和时间（左边是首次对话时间、右边是最近对话时间），当前是哪条规则看顶部那枚开关就行。
7. 点某条会话即在右侧对话区打开它，**小窗保持打开**，可以接着点同一天的下一条。
8. 关掉小窗：再点侧栏那个按钮、点小窗外面、按 `Esc`，或改变窗口大小。

## 工作区颜色

圆点、日期格边框、分组图标、以及每条会话行的描边用的是**同一套工作区颜色**，所以从月历上就能读出「哪天、哪个工作区创建过会话」。

- 当天只有 1 个工作区：日期格是一圈纯色边框。
- 当天有多个工作区：日期格边框取这几个工作区的颜色，以格子中心为圆心铺成角度渐变，每个工作区占一个扇区。
- 「今天」用**加粗的正文色日期 + 一条蓝色下划线**标记（不再用蓝字，深色主题下看不清），「选中」铺**当天的配色**（单工作区纯色、多工作区以格子中心为圆心的角度渐变，每个工作区一个扇区，透明度 50%）+ 加粗；两者都不会覆盖数据色边框。

基础色阶 8 色（按色相排列）：

`#FC757B` `#F97F5F` `#FAA26F` `#FDCD94` `#FEE199` `#B0D6A9` `#65BDBA` `#3C9BC9`

分配规则（N = 工作区数量，按注册表顺序取色，工作区颜色跨日期固定）：

| 情况 | 取法 | 例子 |
|---|---|---|
| N 能整除 8（1、2、4、8） | 在 8 色上等距取 | 4 个工作区 → 第 **1、3、5、7** 色 |
| N 不能整除 8（如 3、5、6、7） | 把色阶重采样到「能整除 N 的最小长度」，再取均匀分布且包含两端的色号 | 3 个工作区 → 9 色阶的第 **1、5、9** 色 |

第 9 色由两端 `#FC757B`、`#3C9BC9` 之间的色阶插值得到（3 个工作区时中间那个是 `#FED797`）。不属于任何工作区的目录分组用中性灰，固定排在最后。

## 安装

需要在 DSH 0.2.2-rc.5 或更高的 0.2.x 上使用。

### 在 DSH 中安装（推荐）

1. 打开 DSH 侧栏 **插件** → **添加插件**。
2. 粘贴包名，点安装：

```sh
@akira-yylm/session-calendar
```

3. 装好后插件默认启用；页面提示 `restart-required` 时重启 DSH，再刷新页面。左侧「免费会话」下方就会出现「会话日历」。

从 npm 安装的版本，插件页会显示 **Versions** 区，升级可以直接点 **Update**。

### 从 GitHub 安装

不想经过 npm、或者想锁死某个提交时，用 GitHub 地址：

```sh
github:Akira-yylm/dsh-session-calendar#v1.1.1
```

想让 Plugin Manager 把它识别为**可更新**的 Git 安装，把 tag 换成完整的 40 位 commit SHA（`git rev-parse v1.1.1` 可查）；写 tag 或分支名也能装，但不会跟随更新。

> 中国大陆网络下 Git 直装可能很慢，建议优先用上面的 npm 方式。

### 用命令安装

```sh
dsh plugin --profile <profile> add @akira-yylm/session-calendar
```

### 从本地目录安装

`git clone` 本仓库后，在 **添加插件** 里选择该目录（本地目录会被 link 安装）。改完代码刷新页面即生效，适合自己改代码时用。

## 升级

- **npm 安装**：插件页出现新版本时点 **Update** 即可。
- **GitHub 安装**：没有一键更新，换新版本 = 移除旧版 → 用新 commit 重新装。

## 数据与隐私

- 只新增一个同 origin 的**只读**宿主接口：`GET /dsh-session-calendar/created.json`，由会话持久层（`sessionPersistence.list()`）读每个会话的 `createdAt`，再只读地取日志**开头**第一条用户消息（`startedAt`，按会话永久缓存）；「最近对话」不需要宿主参与，直接用页面已有的 `SessionSummary.updatedAt`。
- 只读这两段有界的日志切片（开头最多 256 条、结尾最多 96 条），不读整份正文；不写任何文件，不发外网请求，不上传任何数据。
- 会话标题、工作区、排序与归档状态都取自页面已有的会话/工作区数据，不额外复制一份。
- 数据不出本机；卸载后无残留：本插件不创建配置文件、缓存或数据库。

## 限制

- 日期按**浏览器本地时区**划分（例如 Asia/Shanghai），不是 UTC。
  - 开关「首次」= 会话日志里**第一条用户消息**的时间（DSH 会复用空白会话，所以 11-19 建的空壳今天才第一次说话时，算「今天开场」）；
  - 开关「最近」= **最近一次你发消息**的时间，用的是 DSH 自己的会话摘要 `SessionSummary.updatedAt`（= 会话创建时间与最近一次 `user/message` 中较晚的那个）；
  - 两者都**不看命令/状态类事件**：比如「去AI味」胶囊在你打开任意会话时会自动执行一条 `/humanizer status`，这类记录不会把会话挪到「最近对话」的今天。
- 与左侧栏一致地隐藏：**子代理会话**、**空白会话**、**已归档会话**。
- 不属于任何已注册工作区的会话（例如目录已从工作区列表移除）会按文件夹名单独成组。
- 月历只显示当月日期（相邻月份留空），翻月会自动落到该月最早有会话的一天。
- 小窗水平贴左侧栏右缘、纵向在窗口内居中；窗口很矮时会改为整张卡片滚动，窗口很窄时卡片会收窄并可能盖住左侧栏，此时用卡片右上角的关闭按钮收起。
- 入口挂在「新会话」这一行的插槽里，所以当 DSH 自己隐藏该行时（例如当前会话不允许新建会话），「会话日历」按钮也会一起隐藏。

## 关掉或卸载后

「会话日历」按钮与小窗消失。DSH 的会话、工作区、会话顺序、归档状态都不受影响；菜单元数据里也不会留下任何东西。

## 兼容性

- 在 **DSH 0.2.2-rc.5（macOS 桌面端）** 实测；包内声明 `engines.dsh: >=0.2.2-rc.5 <0.3.0`，超出范围 DSH 会拒绝安装或升级。
- 纯 Web UI + 一个只读 Host 路由，不依赖操作系统；Windows / Linux 未实测。
- 与官方插件无冲突：只插入自己的 `session-calendar` 行，不覆盖任何官方 row。

## 开发

| 文件 | 作用 |
|---|---|
| `index.js` | Host 半边：注册只读路由 |
| `client.js` | Client 半边：侧栏入口按钮 + `shell.overlay` 小窗月历 |
| `cordis.patch.yml` | 插入 `session-calendar` 行 |
| `locale/zh.json`、`locale/en.json` | 插件页标题与描述 |
| `icon.svg` | 36×36 透明底图标 |

注意：`client.js` 里的 `window.__ModuleLoader__.load({ id })` 必须与包名完全一致，否则 Host 正常但界面不出现。

本地 link 安装时，改完刷新页面即可看到客户端改动；Host 侧改动需要重启 DSH。
